# Android 客户端现代化 UI 设计

> 状态：已实施（Android v0.5.2-ui 本地迭代版）  
> 适用版本：Android 客户端 0.5.2-ui  
> 产品名称：一起看 / SyncWatch  
> 配套文档：[08-Android客户端现代化UI实施.md](08-Android客户端现代化UI实施.md)

## 1. 设计目标

本次改版聚焦三个结果：

1. **现代但不喧宾夺主**：首页更精致，播放页更沉浸，视频始终是视觉中心。
2. **手势自然且同步可靠**：横滑预览进度、松手一次生效；多人同时操作时仍有明确规则。
3. **手机和平板都不是“拉伸界面”**：手机单栏，平板响应式双栏，横屏全屏使用独立控制层。

### 1.1 本期范围

- 深色主题、蓝紫品牌色、克制科技感。
- 重做创建/加入房间首页。
- 自定义 Media3 播放控制层。
- 横滑 seek、双击播放/暂停、横屏亮度与音量手势。
- 手动横屏、播放锁定、三级消息反馈。
- 手机与平板响应式布局。

### 1.2 非本期范围

- 不修改服务端、WebSocket 协议和房间权威模型。
- 不迁移 Jetpack Compose，不重构为多 Activity。
- 不做滑动静帧缩略图。
- 不做字幕、音轨、投屏、画面比例设置。
- 不做自动旋转、折叠屏铰链姿态适配。
- 不增加在线视频、文件互传或视频分发能力。

## 2. 设计原则

### 2.1 视频优先

播放时减少常驻信息。房间、成员和连接状态在需要时可见，不长期遮挡画面。

### 2.2 主流程少决策

普通用户只需要理解“创建还是加入、昵称、房间码、选择视频”。服务器地址属于高级设置，不参与每次主流程的视觉竞争。

### 2.3 操作结果可预期

手势必须显示目标与结果；离开房间必须确认；远端操作优先于本地未提交的进度预览。

### 2.4 同步操作有归因，但不打扰

保留“谁播放、谁暂停、谁调整进度”的感知，使用轻量胶囊提示代替连续 Toast。

## 3. 品牌与视觉语言

### 3.1 品牌呈现

- 中文主标识：**一起看**。
- 英文辅助标识：**SyncWatch**，使用较小字号和次要文字色。
- 图标采用简洁的播放三角形与连接/双人意象，不重新扩展品牌体系。
- 标语沿用“本地视频零传输 · 多人同步播放”。

### 3.2 色彩令牌

| 令牌 | 建议值 | 用途 |
|---|---|---|
| `bg_page` | `#0B0D12` | 首页与竖屏播放页背景 |
| `bg_surface` | `#141824` | 卡片、输入区、成员面板 |
| `bg_elevated` | `#1C2230` | 弹层、抽屉、悬浮控件 |
| `stroke_subtle` | `#2A3142` | 分隔线与卡片边界 |
| `brand_primary` | `#5368D8` | 主按钮、选中状态 |
| `brand_purple` | `#7656C8` | 主按钮渐变末端、品牌点缀 |
| `brand_light` | `#9AA7FF` | 深色背景上的品牌文字与图标 |
| `text_primary` | `#F5F7FF` | 标题和主要信息 |
| `text_secondary` | `#A6AEC2` | 辅助说明 |
| `text_hint` | `#737D92` | 输入提示，不用于关键正文 |
| `success` | `#35D49A` | 已连接、就绪 |
| `warning` | `#F6C85F` | 重连、片源不一致 |
| `error` | `#FF6B7A` | 播放失败、加入失败 |
| `scrim` | `#99000000` | 播放控制层渐变遮罩 |

主按钮可使用 `brand_primary → brand_purple` 的轻微渐变。页面背景不使用大面积渐变和光斑。

### 3.3 字体与排版

| 层级 | 手机建议 | 用途 |
|---|---:|---|
| 品牌标题 | 30sp / Bold | 首页“一起看” |
| 页面标题 | 22sp / Bold | 创建、加入等主标题 |
| 卡片标题 | 17sp / Medium | 文件、成员、设置标题 |
| 正文 | 15sp / Normal | 输入框、主要说明 |
| 辅助文字 | 13sp / Normal | 状态、注释 |
| 播放器时间 | 13sp / Medium | 当前时间与总时长 |

时间数字使用等宽数字特性，避免进度变化时布局抖动。长片名最多两行，房间码不截断。

### 3.4 形状、间距与触控

- 基础间距单位：4dp；常用间距：8 / 12 / 16 / 20 / 24dp。
- 首页卡片圆角：20dp；输入框圆角：14dp；按钮圆角：14dp。
- 悬浮控制与提示胶囊圆角：16dp 或全圆角。
- 所有可点击区域至少 48dp × 48dp。
- 图标视觉尺寸建议 24dp，但点击热区扩展到 48dp。
- 不用阴影堆叠层级，主要靠背景明度、细描边和遮罩区分。

### 3.5 动效

- 页面与面板转场：180–250ms。
- 按钮、选中态、控制层显隐：120–180ms。
- 控制层使用淡入淡出，不做夸张缩放。
- 不使用持续粒子动画、无限呼吸光效和大面积实时模糊。
- 系统开启“移除动画”时尊重系统设置。

## 4. 信息架构与主流程

```text
启动
  └─ 首页（昵称与服务器配置可复用）
       ├─ 创建房间
       │    └─ 选择本地视频 → 创建 → 播放页 → 复制房间码给朋友
       └─ 加入房间
            └─ 输入房间码/可选密码 → 选择同一视频 → 加入 → 播放页
```

选视频仍是进房前必要步骤，不改变当前加入时序。房间码不存在而意外创建新房间时，继续使用阻断式提示，不允许用户误以为加入了朋友房间。

### 5.1 手机线框

```text
┌──────────────────────────────────┐

│    SYNCWATCH                     │
│    各自本地片源，此刻同步观看     │
│                                  │
│  ┌──────────────────────────────┐ │
│  │ [ 创建房间 ] [ 加入房间 ]    │ │
│  │                              │ │
│  │ 你的昵称                     │ │
│  │ [ 输入昵称                 ] │ │
│  │                              │ │
│  │ 本地视频                     │ │
│  │ ┌──────────────────────────┐ │ │
│  │ │ 🎬 选择视频              │ │ │
│  │ │ 需与好友使用同一片源      │ │ │
│  │ └──────────────────────────┘ │ │
│  │                              │ │
│  │ 加入模式额外显示：           │ │
│  │ [ 6 位房间码               ] │ │
│  │ [ 房间密码（可选）         ] │ │

│  └──────────────────────────────┘ │

└──────────────────────────────────┘
```

### 5.2 创建与加入模式

| 内容 | 创建房间 | 加入房间 |
|---|---|---|
| 昵称 | 显示 | 显示 |
| 本地视频 | 显示 | 显示 |
| 房间码 | 不显示 | 必填，支持大写自动转换 |
| 房间密码 | 可折叠为“设置房间密码” | 可折叠为“房间有密码” |
| 主按钮 | 创建并开始观看 | 加入房间 |

- 默认记住上次昵称和上次模式；是否记住房间码沿用当前行为。
- 选择文件后，文件卡显示文件名、已选状态和“更换”入口。
- 主按钮在未满足必要条件时可点击并给出具体缺失项，不让用户无反馈地等待。
- 高级设置展开后显示服务器地址和简短说明；普通状态不占用首屏主要空间。

### 5.3 平板首页

可用宽度达到 600dp 后，内容居中并限制最大宽度，避免输入框横跨整个大屏。可使用左右两栏：左侧品牌与隐私说明，右侧操作卡片；竖向空间不足时允许滚动。

## 6. 播放页设计

### 6.1 手机竖屏

```text
┌──────────────────────────────────┐
│ 系统状态栏                        │
│ ┌──────────────────────────────┐ │
│ │          16:9 视频           │ │
│ │      单击显示控制层            │ │
│ └──────────────────────────────┘ │
│ 片名                       已连接 │
│ ┌──────────────────────────────┐ │
│ │ 房间码 ABC123        [复制]   │ │
│ │ 3 人在线 · 全员就绪            │ │
│ │ [成员] [倍速] [全屏]           │ │
│ └──────────────────────────────┘ │
│ 操作提示将在这里轻量显示            │
└──────────────────────────────────┘
```

- 视频保持正确宽高比，不拉伸。
- 房间卡显示房间码、在线人数和汇总状态。
- 成员面板默认折叠；展开后显示昵称、播放/暂停/缓冲状态及片源时长异常。
- 竖屏横滑 seek 可用；亮度和音量手势不在竖屏启用。

### 6.2 手机横屏全屏

```text
┌────────────────────────────────────────────┐
│ ‹  片名              ABC123 复制  🔒  ⚙   │ ← 顶部渐变
│                                            │
│               视频画面                     │
│       [快退10s]   [播放/暂停]   [快进10s]   │
│                                            │
│  12:34  ━━━━━●────────  1:48:20  1.0x  □ │ ← 底部渐变
└────────────────────────────────────────────┘
```

- 顶部：返回、片名、房间码复制、播放锁定、成员入口。
- 中部：快退 10 秒、播放/暂停、快进 10 秒。
- 底部：当前时间、进度条、总时长、倍速、退出全屏。
- 成员信息以侧边抽屉显示，不与视频控制争用常驻空间。
- 所有控制位于安全区内，避开刘海、圆角和系统手势边缘。

### 6.3 平板播放页

- **竖屏/非全屏且宽度 ≥600dp**：采用双栏。主区域放视频与核心控制，侧栏放房间、成员和片源状态。
- **横屏全屏**：与手机一致的视频沉浸模式，成员信息使用右侧抽屉；控件最大宽度受限，避免时间栏过长。
- 宽度变化只改变布局，不重建房间，不重置播放器。

## 7. 播放控制与手势规范

### 7.1 手势总表

| 手势 | 使用场景 | 行为 | 是否同步 |
|---|---|---|---|
| 单击画面 | 未锁定 | 显示/隐藏控制层 | 否 |
| 双击画面中央 | 未锁定 | 播放/暂停 | 是 |
| 横向滑动 | 未锁定，非进度条拖动 | 连续预览目标进度，松手一次 seek | 松手后是 |
| 横屏左侧纵滑 | 未锁定 | 调整本机亮度 | 否 |
| 横屏右侧纵滑 | 未锁定 | 调整本机媒体音量 | 否 |
| 点击快退/快进 | 未锁定 | -10s / +10s | 是 |
| 点击锁定 | 横屏 | 禁用其他画面手势和普通控制 | 否 |

### 7.2 横滑 seek

**触发与计算**

- 水平位移超过约 10dp，且明显大于竖向位移后进入 seek。
- 以手指按下时的实际播放位置为基准，不以每一帧的新位置累加。
- 完整横滑可用宽度约对应 90 秒。
- 目标位置限制在 `0～duration`；未知时长时不允许自由 seek。
- 控制按钮和进度条上的触摸不触发画面手势。

**滑动中反馈**

```text
             ┌──────────────────────┐
             │      42:18 / 1:48:20  │
             │        快进 +00:36    │
             │  ━━━━━━━━━●─────────  │
             └──────────────────────┘
```

- 显示目标时间、总时长、快进/快退方向和相对偏移。
- 只更新预览 UI，不持续调用播放器 seek，不发送网络消息。
- 本期不显示抽帧缩略图。

**松手、取消与同步**

- 松手后执行一次实际 seek，再由现有播放器事件进入同步链路。
- seek 前播放则继续播放；seek 前暂停则保持暂停。
- 系统取消触摸时取消预览，不提交 seek。
- 收到远端 seek 时立即取消本地预览，应用远端位置，并显示“某某调整了进度，本次滑动已取消”。
- 远端播放/暂停仍正常生效；不得因本地手势而延迟或覆盖。

### 7.3 双击与单击

- 单击控制层的判定可等待约 200ms，以排除双击。
- 控制层中的播放/暂停按钮立即响应，不等待双击判定。
- 本期不提供双击左右区域 ±10 秒，避免与横滑和按钮功能重复。

### 7.4 亮度与音量

- 仅横屏全屏启用。
- 左半屏纵滑调整窗口亮度；右半屏纵滑调整媒体音量。
- 中央显示百分比或音量条，停止操作后自动消退。
- 手势一旦判定为横向，就不能再变成纵向，反之亦然。
- 亮度与音量只影响本机，不进入同步协议。
- 离开播放页时恢复进入前的窗口亮度；音量由系统管理，不擅自恢复。

### 7.5 播放锁定

- 横屏控制层提供锁定图标。
- 锁定后隐藏普通控制，仅保留解锁按钮。
- 锁定期间禁用 seek、亮度、音量、单击和双击手势。
- 远端播放、暂停和 seek 仍正常执行。
- 锁定不是网络房间的“锁定”，文案避免产生歧义。

## 8. 控制层生命周期

- 播放中：3 秒无操作自动隐藏。
- 暂停、缓冲、成员面板展开、手势反馈期间：保持显示。
- 用户操作任意控件：重新计时。
- 控制层隐藏不等于播放锁定；隐藏后仍可单击唤醒和使用画面手势。
- 缓冲时显示明确指示，不把缓冲误画成用户暂停。

## 9. 消息与异常反馈

| 级别 | 示例 | 呈现方式 |
|---|---|---|
| 轻提示 | 小明播放了、房间码已复制 | 顶部小胶囊，约 2 秒消退 |
| 持续状态 | 正在重连、已断线 | 房间内状态条，恢复后消失 |
| 阻断错误 | 密码错误、文件不可读、播放失败 | 页面内错误卡片或对话框 |

- 同类加入/离开消息可合并，避免刷屏。
- 操作归因包含操作者和目标时间，但不长期遮挡画面。
- 播放错误除通俗说明外，可保留错误码供排障。
- 房间码不存在却创建新房间属于阻断提示，必须有“返回重新输入”路径。

## 10. 返回、方向与离开

- 首页和竖屏播放页保持竖向，不随设备自动旋转。
- 点击全屏进入固定横屏，点击退出全屏返回竖屏。
- 横屏按系统返回：先退出全屏，不离开房间。
- 竖屏播放页按返回：弹出“离开房间？”确认。
- 离开确认文案说明“将断开与当前房间的同步”，提供“继续观看 / 离开房间”。
- 切后台暂停的现有产品行为保持不变，不在本次 UI 改版中暗改。

## 11. 可访问性与可用性

- 正文和关键图标保持足够对比度，不仅靠颜色表达连接或错误状态。
- 图标按钮具备内容描述；播放、暂停、锁定状态可被无障碍服务识别。
- 系统字体放大时，首页允许滚动，关键按钮不被挤出屏幕。
- 时间、房间码和错误信息不能被刘海或系统栏遮挡。
- 进度条除拖动外，可配合 ±10 秒按钮完成精确度要求较低的操作。

## 12. 设计验收清单

- [ ] 首页第一眼能区分创建和加入，不必理解服务器参数。
- [ ] 深色背景上正文、输入文字、提示文字均清晰。
- [ ] 手机竖屏、手机横屏、平板竖屏、平板横屏均无控件重叠。
- [ ] 视频比例正确，控制层不妨碍核心画面。
- [ ] 横滑反馈及时，松手后只发生一次 seek 和一次同步。
- [ ] 远端 seek 能取消本地预览，本地旧目标不会回写。
- [ ] 亮度、音量、进度手势不会互相串扰。
- [ ] 锁定后只有解锁可操作，远端同步仍正常。
- [ ] 返回不会意外退房，意外创建房间仍有阻断提示。
- [ ] 普通同步消息不会形成连续 Toast 遮挡。
